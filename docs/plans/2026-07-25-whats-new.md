# What’s New Implementation Plan

> **For Hermes:** Implement task-by-task with TDD and fresh verification.

**Goal:** Tambah halaman pembaruan produk Cubiqlo yang mudah ditemukan dan badge New sampai rilis terbaru dibaca.

**Architecture:** Data rilis statis tersentral di `src/lib/product-updates.ts`. Halaman authenticated merender timeline dari data itu. Client marker menyimpan latest release ID di `localStorage`; sidebar menampilkan badge New bila ID tersimpan berbeda. Tidak ada DB atau CMS pada MVP.

**Tech Stack:** Next.js App Router, React, TypeScript, Tailwind, Vitest, localStorage.

---

### Task 1: Model data rilis
- Create `src/lib/product-updates.ts`.
- Create `src/lib/product-updates.test.ts`.
- Test latest release, urutan tanggal, kategori valid.

### Task 2: Halaman What’s New
- Create `src/app/(app)/app/whats-new/page.tsx`.
- Create client marker untuk mencatat latest release saat halaman dibuka.
- Tampilkan judul, ringkasan, tanggal, kategori New/Improvement/Fix, dan CTA opsional.

### Task 3: Navigasi dan badge
- Modify `src/components/app-sidebar.tsx`: utility link dekat footer, icon Sparkles, badge New, active state, mobile ikut sidebar.
- Modify `src/components/app-topbar.tsx`: link What’s New di dropdown mobile/account utility.
- Badge hilang setelah halaman dibuka dan muncul kembali jika latest release ID berubah.

### Task 4: Verify dan release
- Run targeted test, full test, ESLint touched files, TypeScript, build.
- Browser QA desktop/mobile: nav, badge, halaman, mark-read.
- Commit, push, deploy existing `cubicle` service; verify health and public ports.
