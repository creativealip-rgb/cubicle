## 🎯 Workflow Utama

### 1. Dapatkan Klien
```
Landing Page Builder → Share URL → Contact Form → Lead masuk email
```

### 2. Kelola Proyek
```
Buat Klien → Buat Proyek → Bikin Task → Assign ke tim
```

### 3. Catat Waktu
```
Timer / Input Manual → Time entries → Siap ditagih
```

### 4. Kirim Invoice
```
Import Waktu → Tambah Item → Kirim Invoice → Klien Bayar → Tandai Lunas
```

### 5. Share ke Klien
```
Aktifkan Portal → Share link → Klien lihat progres, file, invoice
```

## 🔧 Setup Awal

1. **Lengkapi workspace** — `/app/settings` (nama, logo, alamat)
2. **Atur invoice defaults** — `/app/settings?tab=branding` (mata uang, pajak, terms)
3. **Tambah klien pertama** — `/app/clients`
4. **Buat proyek pertama** — `/app/projects`
5. **Jalankan timer** — `/app/time`
