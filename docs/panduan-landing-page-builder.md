# Panduan Landing Page Builder

Bikin halaman landing profesional dalam hitungan menit — tanpa coding.

---

## 1. Akses Builder

1. Login ke [app.cubiqlo.com](https://app.cubiqlo.com)
2. Sidebar → **Personal** → **Landing Page**

---

## 2. Tab Insert — Tambah Konten

Di tab **Insert**, kamu bisa:

### Starter Blocks (Template Siap Pakai)
Drag & drop template section langsung ke canvas. Contoh:
- **Layanan 3 Kartu** — showcase 3 layanan
- **Pricing 3 Paket** — tabel harga
- **FAQ 5 Pertanyaan** — tanya jawab
- **CTA Utama** — call-to-action button
- **Testimoni 3 Klien** — social proof

### Widget (Komponen Dasar)
Klik untuk tambah komponen individual:
- **Teks** — paragraf custom
- **Layanan / Proses / Harga** — konten bisnis
- **Portofolio / Galeri** — showcase visual
- **FAQ / Accordion** — konten collapsible
- **Kontak / Sosial / Embed** — integrasi eksternal

> 💡 **Tip:** Drag template dari sidebar ke posisi yang kamu mau di canvas. Atau klik untuk tambah di akhir halaman.

---

## 3. Tab Pages — Multi-Page

Bikin beberapa halaman dalam satu landing page:

1. Buka tab **Pages**
2. Klik **Tambah Page**
3. Beri nama halaman (contoh: "Tentang Kami", "Harga")
4. Set halaman utama dengan ikon 🏠
5. Pindah antar halaman lewat klik **Edit**

Setiap halaman punya sections sendiri. Halaman non-home muncul sebagai tab navigasi di public page.

---

## 4. Tab Templates — Template Siap Pakai

Langsung ganti seluruh halaman dengan template:

1. Buka tab **Templates**
2. Filter berdasarkan kategori
3. Pilih template yang cocok
4. Klik **Apply Template**
5. Konfirmasi jika halaman sudah ada konten

> ⚠️ **Hati-hati:** Apply template mengganti semua konten halaman saat ini.

---

## 5. Tab Theme — Styling Visual

### Theme Siap Pakai
8 tema preset yang langsung klik:
- **Midnight** — dark mode elegan
- **Paper** — hangat & natural
- **Studio** — modern minimalis
- **Ocean / Forest / Sunset / Rose** — tema warna spesifik
- **Dark** — full dark mode

### Custom Colors
Atur warna sendiri:
- **Primary Color** — warna utama (tombol, aksen)
- **Background Color** — warna latar
- **Text Color** — warna teks
- **Secondary Color** — warna pendukung

### Tipografi
- **Heading Font** — font judul
- **Body Font** — font isi
- **Header Style** — full-width / contained / minimal
- **Button Style** — rounded / pill / square

---

## 6. Tab Structure — Atur Ulang Section

Lihat dan atur semua section dalam list:

1. Buka tab **Structure**
2. Drag & drop baris untuk reorder section
3. Klik baris untuk seleksi + scroll ke section di canvas
4. Lihat preview konten di setiap baris

---

## 7. Canvas Editor

### Edit Konten
- **Klik** section untuk seleksi
- **Klik langsung** teks untuk edit inline
- **Klik gambar** untuk upload/ubah

### Toolbar Section
Saat section dipilih, muncul toolbar:
- ↕️ **Move Up/Down** — pindah posisi
- 📋 **Duplicate** — copy section
- 🗑️ **Delete** — hapus section

### Properties Panel (kanan)
Panel properti muncul saat section dipilih:
- Edit judul, deskripsi, item
- AI Copy Generator — generate konten otomatis

### Device Preview
Preview tampilan di berbagai ukuran:
- 🖥️ **Desktop**
- 📱 **Tablet**  
- 📱 **Mobile**

### Undo / Redo
- `Ctrl+Z` — undo
- `Ctrl+Shift+Z` — redo
- Maksimal 50 langkah history

---

## 8. Tab SEO — Optimasi Pencarian

1. Buka tab **SEO**
2. Isi:
   - **SEO Title** — judul di hasil Google (max 80 karakter)
   - **SEO Description** — deskripsi di hasil Google (max 180 karakter)
   - **OG Image URL** — gambar thumbnail saat dibagikan
3. Preview tampilan WhatsApp/Google
4. Copy link publik

---

## 9. Publish & Unpublish

### Cek Kesiapan
Badge **Readiness** di bottom bar menunjukkan status:
- 🟢 **Siap publikasi** — semua mandatory field terisi
- 🟡 **N hal perlu diperbaiki** — klik badge untuk lihat detail

### Publish
1. Pastikan readiness badge hijau
2. Klik tombol **Draft** di bottom bar
3. Konfirmasi "Publikasikan halaman ini?"
4. Status berubah jadi **Live** 🟢

### Unpublish
1. Klik tombol **Live**
2. Konfirmasi "Sembunyikan halaman dari publik?"
3. Status kembali jadi **Draft**

### URL Publik
Setelah publish, halaman bisa diakses di:
```
cubiqlo.com/site/[slug-kamu]
```

Ubah slug di tab Publish (mobile) atau di SEO panel (desktop).

---

## 10. Mobile Editor

Di HP/tablet, builder otomatis berubah jadi step-by-step wizard:

1. **Pages** — atur halaman
2. **Sections** — tambah/hapus/reorder section
3. **Theme** — pilih tema & warna
4. **Publish** — slug, SEO, publish toggle

---

## 11. AI Copy Generator

Generate konten section otomatis dengan AI:

1. Pilih section di canvas
2. Buka **Properties Panel** (kanan)
3. Scroll ke **Generate Copy**
4. Isi brief:
   - Nama bisnis
   - Target audiens
   - Produk/jasa
   - Tone (profesional, santai, friendly)
5. Klik **Generate**
6. Preview hasil → **Apply** atau **Discard**

Section yang support AI:
- Layanan (3 kartu)
- FAQ (5 pertanyaan)
- CTA

---

## 12. Contact Form Publik

Setiap landing page otomatis punya form kontak di bagian bawah.

**Untuk pengunjung:**
1. Isi Nama, Email, Pesan
2. Telepon opsional
3. Klik **Kirim Pesan**

**Untuk pemilik:**
- Pesan dikirim ke email workspace owner via Resend
- Rate limit: 3 pesan/jam per IP
- Anti-spam: honeypot field

## Tips & Trick

| Tips | Detail |
|---|---|
| **Hero image** | Upload gambar besar di bagian paling atas — tampil sebagai background |
| **CTA button** | Tambah tombol CTA di awal dan akhir halaman |
| **Testimoni dulu** | Social proof di atas lipat meningkatkan konversi |
| **Mobile cek** | Selalu preview di mobile sebelum publish |
| **Slug pendek** | Pakai slug singkat & deskriptif (contoh: `/site/alip-studio`) |
| **SEO title** | Judul SEO berbeda dengan judul halaman — lebih keyword-rich |

## FAQ

**Q: Bisa custom domain?**
A: Saat ini landing page di `cubiqlo.com/site/[slug]`. Custom domain coming soon.

**Q: Bisa multiple landing page?**
A: Satu workspace = satu landing page dengan multiple sub-pages.

**Q: AI generator gratis?**
A: Ya, termasuk dalam paket Cubiqlo (ada monthly cap).

**Q: Contact form kirim kemana?**
A: Ke email workspace owner yang terdaftar.

**Q: Gimana cara lihat siapa yang kirim contact form?**
A: Masuk ke email kamu — setiap submission dikirim via Resend.
